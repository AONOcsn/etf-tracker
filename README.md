# ETF 投资跟踪

适合 iPhone 使用的个人投资账本。支持查看券商资产、执行每月定投、核对成交和资金流水。数据保存在当前浏览器的 IndexedDB 中，无需账号；正式构建支持离线使用。应用不会自动交易。

## 本地体验

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5180 --strictPort
```

打开 http://127.0.0.1:5180/ 。首次使用为空账本，先在「设置 → 投资参数」确认基础月投、额外预算、历史高点和投入比例。线上地址为 https://aonocsn.github.io/etf-tracker/ 。

本地地址与 GitHub Pages 手机站点的账本相互独立。需要体验原有数据时，从原站导出 JSON，在本地「设置 → 数据与备份」导入。

```powershell
npm test
npm run typecheck
npm run build
```

## 四个页面

| 页面 | 用途 |
| --- | --- |
| 总览 | 券商资产、持仓盈亏、本月进度、实际持仓、待处理记录，手动核对现金 |
| 计划 | 查看月份、观察行情、各 ETF 计划与实际、剩余投入；直接记买入 |
| 记录 | 成交、分红、换汇、入金、出金及旧批次；搜索、筛选、详情、编辑与删除 |
| 设置 | 投资参数、标的管理、账户与币种、行情更新、备份恢复、帮助 |

「记一笔」统一打开六类表单：买入、卖出、分红、换汇、入金、出金。记录页可以组合类型、月份、标的、账户及关键词筛选；关键词包含备注。统一的是展示入口，底层账目与各自计算口径保持独立。

## 录入与草稿

- 每类表单保留一份草稿，关闭、切页或刷新后可继续。草稿独立保存，不计入资产与计划，也不进入普通 JSON/CSV 导出或恢复点。
- 正式保存前检查日期、金额、费用、份额及超卖；不完整内容保留在草稿中。旧账本的不完整记录仍可查询和修正。
- 相同日期、方向、标的、金额和份额的成交会提醒重复，确认后仍可保存。
- 计划直达买入会预选标的、日期和定投用途，显示参考金额；实际金额和份额需要填写。
- 换汇、入金、出金沿用上一次的账户和币种，金额及到账信息留空。入金、出金可记录在途状态，到账金额与到账日期需一起填写。

## 计算与兼容

- 持仓成本采用移动加权平均法；同日成交沿用原始录入顺序。卖出按此前平均成本扣减，差额计入已实现盈亏。
- 总览只展示实际持仓，保留清单外标的；缺少价格时提示估值不完整。
- 券商现金由用户核对，独立存储为 `settings.cashUsd` 和核对时间，不根据换汇、转账自动推算。旧版 ETF 行上的现金只在首次迁移时汇总，新字段存在时不重复累加。
- 「本月投入比例」在投资参数中统一编辑，用于分配新增投入；标的管理中的「持仓目标占比」用于核对配置，二者相互独立。
- 回撤低于 10% 使用基础额，10% 至不足 20% 加 250 美元，20% 及以上加 500 美元；额外投入受剩余预算限制。历史高点只增不减，预算按有效定投成交消耗，不因反弹自动恢复。
- 分红再投与其他用途的买入不计入定投进度。非法或超卖记录不计入有效成交。
- 到账 USD 保留当前嘉信渠道口径，内部中转不重复计入；出金不计入到账额，也不影响持仓成本。
- 当前仍为单券商资产统计；银行、其他账户和币种保留在资金流水中。账户改名不会静默改写历史记录。
- 仅默认展示当前月及已有内容的月份，其他月份按需选择。旧月份、备注和旧批次仍保存在账本中。

## 备份与恢复

数据不会随 GitHub 仓库同步。换设备、清理浏览器数据之前，请导出外部 JSON 备份。

- **JSON**：正式账本完整备份，兼容旧版 JSON。导入先校验版本和字段，再显示数量供确认；导入会覆盖当前正式账本。
- **CSV**：成交、换汇、入金、出金和分红，带 UTF-8 BOM，方便 Excel 查看。
- **每日快照**：改动后更新当天快照，保留最近 7 份。
- **操作前恢复点**：删除、导入覆盖、回滚、重新开始及旧版字段升级前保留，独立保留最近 7 份。
- **保存失败**：显示错误与重试入口；读取失败时阻止用空白账本覆盖旧数据。

快照和草稿仍在同一浏览器中，不能替代外部备份。

## 行情与交易时段

点击「更新行情」会请求腾讯公开行情接口，查询所配置的标的和标普 500。对方能看到 IP 与查询代码，请求不包含持仓数量、投资金额或账户。接口失败时保留旧值，支持手工修正价格；手工观察月份不会被行情更新覆盖。

总览提供紧凑时段提示，计划中可展开详情，时间固定显示北京时间。节假日与提前收盘表目前覆盖 2026–2027，超出范围会提示人工核对。实际可下单时段与订单执行以券商规则为准。

## iPhone 验收与后续发布

`main` 分支推送后，现有 GitHub Actions 工作流会运行测试、构建并部署 GitHub Pages。用 Safari 打开站点，通过「分享 → 添加到主屏幕」安装，首次在线载入后检查离线启动。

更新版本后，在 Safari 在线打开站点等待更新，再重开主屏幕应用；「设置」底部显示构建版本时间。真实 iPhone 的主屏幕启动、离线与缓存更新须在设备上验收；桌面手机宽度测试不能替代它们。

## 开发说明

测试使用 Node 内置运行器覆盖成本、预算、资金统计、备份、迁移、草稿、筛选、录入校验和交易时段。表单异步保存测试通过 Vite 转换实际 TSX，不新增测试框架。

沙箱中 npm 缓存权限受限时，可用 `$env:npm_config_cache = "$PWD\.npm-cache"`；该目录已忽略。当前保留原始账本版本 1，通过可选字段与规范化过程兼容旧数据。
